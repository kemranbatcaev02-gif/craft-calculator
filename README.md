# ⛏️ Minecraft Craft Calculator

Десктопный калькулятор ресурсов для крафта в Minecraft. Вводишь предмет и количество — получаешь полный список сырья, которое нужно добыть, дерево промежуточных крафтов и порядок действий.

## Возможности

- **Рекурсивный расчёт** — любой предмет разбирается до сырья (брёвен, руды, алмазов) с учётом округления вверх при крафте партиями
- **Дерево крафта** — разворачиваемая визуализация: что из чего состоит, сколько раз крафтить каждый шаг
- **Список шагов** — сколько раз скрафтить каждый промежуточный предмет, чтобы получить нужное количество
- **97 предметов** — инструменты, оружие, броня, еда, механизмы, транспорт, декор, все базовые деревянные/каменные/железные/алмазные наборы
- **Поиск с подсказками** — начинаешь вводить название, ниже сразу выпадают совпадения
- **Каталог по категориям** — просто кликаешь на предмет, чтобы открыть расчёт
- **Избранное и история** — быстрый доступ к тому, что считал раньше
- **Тёмная/светлая тема, 5 акцентных цветов**

## Установка и запуск

```bash
git clone https://github.com/kemranbatcaev02-gif/craft-calculator.git
cd craft-calculator
pip install -r requirements.txt
python main.py
```

## Как это считается

Для каждого предмета рекурсивно проходим дерево рецепта:

```
craft_count = ceil(нужное_количество / выход_за_один_крафт)
```

Если рецепт даёт больше, чем нужно (например, 4 доски из 1 бревна, а нужно 3),
остаток учитывается — калькулятор всегда округляет вверх, чтобы хватило с запасом.

## Добавить свой предмет

Открой `data/items.json` и `data/recipes.json` — формат простой:

```json
// items.json
"my_item": {"name": "Моё изделие", "category": "Инструменты", "icon": "🔧"}

// recipes.json
"my_item": {"yield": 1, "ingredients": {"stick": 2, "iron_ingot": 1}}
```
